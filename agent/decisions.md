# Decisions

This file documents key decisions made during development that are not covered by architecture.md (which focuses on high-level design).

## Purpose
- Record implementation choices and their rationale
- Document trade-offs considered
- Provide context for future development

## Format
Each decision should include:
- **Decision**: What was decided
- **Context**: Why the decision was needed
- **Rationale**: Why this option was chosen
- **Alternatives**: What other options were considered
- **Related**: Cross-references to architecture.md, goals.md, or journal.md
